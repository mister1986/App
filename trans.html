If something goes wrong

“Could not load the speech model.” The model is fetched from a CDN the first time you run it, so you need to be online for that first run. If you saved this page to your disk, open it through a small local server rather than double-clicking it — browsers block module loading on file://. From the folder containing this file run python3 -m http.server 8000 and visit http://localhost:8000/transcriber.html.

“Could not read the audio.” The browser decodes the file itself, so exotic codecs (some MKV and MOV variants) can fail. Convert first: ffmpeg -i input.mov -ac 1 -ar 16000 output.wav.

It is slow. WebGPU (Chrome and Edge) is many times faster than the CPU fallback. On CPU, expect roughly real-time on Standard — an hour of audio takes about an hour. Drop to Draft for long files, or split them up.

Accuracy. This runs the Whisper family of models. Clean single-speaker audio comes out very well; heavy crosstalk, music, and thick accents do not. It does not label who is speaking.
